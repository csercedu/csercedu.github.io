# 주간교육뉴스 자동화 (기독교학교교육연구소)

매일 교육 기사를 모으고, 매주 AI가 5건을 골라 요약하면, 사람이 확인한 뒤
카드뉴스·뉴스 페이지·메일·카톡 문안까지 자동으로 만들어 보내는 프로그램입니다.
**운영 비용은 0원**입니다. (GitHub 공개 저장소 + GitHub Pages + Gemini 무료 등급 + Cloudflare Workers AI 무료 등급 + Gmail)

## 한 주의 흐름

| 언제 | 무엇이 | 사람이 할 일 |
|---|---|---|
| 매일 오전 6시 | 26개 언론사에서 교육 기사 수집 → 기사 고르기 화면(`/review/`) 갱신 | 없음 |
| 아무 때나 (목요일까지) | — | 고르기 화면에서 기사를 눌러 고르고 '카드뉴스 만들기' → GitHub 'Create' |
| 요청 후 약 5분 | 고른 기사만 AI가 카드 문구·사진 작성 → 카드·미리보기 → 요청 글에 댓글·카톡 | 미리보기 확인, 필요하면 수정 |
| 요청 글에 `발행` 댓글 | 뉴스 페이지 공개, 구독자 메일, 카톡 '나에게 보내기' | 단체방 전달, 채널 '소식'·게시판·홈페이지 뉴스레터 붙여 넣기 |
| 목요일 오후 6시 | 아직 안 골랐으면 '기사를 골라 주세요' 알림 (원하면 AI가 대신 고르기) | — |

## 폴더 안내

```
config/        ← 연구소가 직접 고치는 설정
  keywords.csv   키워드(분류·가중치·사용 여부)
  sources.csv    언론사 RSS 목록
  exclude.txt    제외할 단어
  editorial.md   AI 편집 기준(무엇을 고르고 어떻게 쓰는지)
  settings.yml   호수, 발행 요일, AI 모델, 확인 필수 여부, 페이지 주소
  links.yml      메인 링크 페이지의 버튼 목록 (구독, 카톡 채널, 홈페이지 등)
issues/        ← 호마다 폴더 하나 (draft.yml = 그 호의 원고, cards/ = 카드 이미지)
scripts/       ← 프로그램 (collect → ai_select → render_cards → build_site → notify, pipeline 이 전체 진행)
templates/     ← 카드·페이지·메일 디자인
.github/workflows/  ← 자동 실행 일정
examples/      ← 2026-11-20 기사로 만든 시연 결과물
```

설치와 매주 운영 방법은 **SETUP.md** 를 보세요.
